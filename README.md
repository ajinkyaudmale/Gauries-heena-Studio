# GAURIÉ Henna Studios

Luxury Indian mehendi artistry studio website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Next.js 15** — App Router, SSR, SEO
- **TypeScript** — Type-safe development
- **Tailwind CSS v4** — Utility-first styling with custom brand tokens
- **Framer Motion** — Elegant scroll and interaction animations
- **Lucide React** — Premium icon set

## Project Structure

```
src/
├── app/              # Next.js app router (layout, page, globals)
├── components/
│   ├── layout/       # Navbar, Footer, FloatingWhatsApp
│   ├── sections/     # Homepage sections
│   └── ui/           # Reusable UI components
└── lib/              # Constants, data, utilities
```

## Configuration

Update contact details in `src/lib/constants.ts`:

- WhatsApp number
- Email and phone
- Instagram URL

## Build

```bash
npm run build
npm start
```
